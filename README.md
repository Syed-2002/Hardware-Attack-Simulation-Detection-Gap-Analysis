## Project Overview

USB cables are trusted everyday accessories. O.MG cables are research tools that hide programmable electronics inside a normal-looking USB cable. They are used in security research and penetration testing, but the same capability can be misused if users and organizations are unaware.

This project studies the O.MG cable at a high level, explains the threat model, presents sanitized awareness demonstrations, and recommends countermeasures for individuals and organizations.

---

## Objectives

- Explain what O.MG cables are and why they matter.
- Describe the threat model at a high level.
- Present sanitized, non-actionable awareness demonstrations.
- Identify risks to users and organizations.
- Recommend practical countermeasures.
- Promote ethical and legal use of security research tools.

## Key Takeaways

- A cable can be more than a cable.
- Trust boundaries matter: if you did not bring it, do not plug it in.
- Use charge-only cables or USB data blockers where appropriate.
- Organizations should enforce USB device control, endpoint management, and user awareness training.
- Security is a combination of technology, policy, and people.

---

## Countermeasures Summary

**For individuals:**
- Never use unknown or found cables.
- Prefer organization-issued accessories.
- Use charge-only cables or a USB data blocker.
- Lock your screen when away from your device.
- Report suspicious cables.

**For organizations:**
- Enforce USB device control policies.
- Use Unified Endpoint Management (UEM).
- Restrict unnecessary USB device classes.
- Disable autorun/autoplay.
- Monitor USB device connections.
- Conduct regular security awareness training.
